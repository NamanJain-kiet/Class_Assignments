Introduction

This website demonstrates how HTML hyperlinks can be used to navigate between different sections of a webpage and between different webpages.

Smart Navigation

02
RESOURCES

Reference

The webpage is based on fundamental HTML concepts including anchor tags, hyperlinks, headings, paragraphs and section IDs.

The href attribute defines the destination of a link. Internal links use IDs such as #introduction, while external page links can point to files such as about.html.

HTML ● ● ●
<a href="#introduction"> Introduction </a>

This project demonstrates both internal navigation and navigation between multiple HTML pages.
